# Сравнение прайса с ценами Ozon, Яндекс.Маркета и Wildberries

Берёт прайс в `.xlsx` (название, категория, цена), ищет каждый товар на трёх
площадках, усредняет цену по первым пяти **подходящим** позициям выдачи и
возвращает тот же файл с дописанными столбцами.

## Почему это запускается локально, а не в сессии Claude

Сессия Claude Code на вебе ходит в интернет через egress-прокси, и домены
маркетплейсов в нём закрыты — `ozon.ru`, `market.yandex.ru`, `wildberries.ru`
и `search.wb.ru` отвечают `403 CONNECT tunnel failed`. Обходить эту политику
нельзя, поэтому сбор выполняется на вашей машине, где сеть не ограничена.

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

`playwright install` нужен для Ozon и Яндекс.Маркета: они отдают выдачу только
настоящему браузеру. Wildberries работает без него.

Если Chromium в системе уже есть, а `playwright install` недоступен, укажите
путь к нему: `--chromium-path /usr/bin/chromium`.

## Запуск

```bash
python run.py --input прайс.xlsx --output прайс_с_ценами.xlsx
```

Прогон по всем трём площадкам занимает часы: паузы между запросами стоят
намеренно, без них Ozon и Маркет начинают отдавать капчу. Результат каждого
запроса пишется в `prices.sqlite3` сразу, поэтому прерванный прогон
продолжается с места остановки — просто запустите ту же команду снова.

Полезно начать с малого, чтобы убедиться, что площадки отвечают:

```bash
python run.py --input прайс.xlsx --limit 20
```

### Ключи

| Ключ | Назначение |
|---|---|
| `--sources ozon,yandex,wb` | какие площадки опрашивать |
| `--limit N` / `--offset N` | часть прайса; удобно, чтобы разбить работу |
| `--top-n 5` | сколько позиций усреднять |
| `--scan-depth 30` | сколько позиций выдачи просматривать в поисках подходящих |
| `--retry-failed` | повторить только то, что в прошлый раз не собралось |
| `--no-headless` | показать окно браузера, чтобы вручную пройти капчу |
| `--report-only` | пересобрать `.xlsx` из уже накопленной базы, ничего не запрашивая |
| `--db путь` | другой файл чекпоинта |
| `--chromium-path путь` | готовый Chromium вместо скачанного Playwright |

## Что появляется в файле

К исходному листу дописываются столбцы, строки и их порядок не меняются:

| Столбец | Смысл |
|---|---|
| `Ozon: средняя цена` | среднее по подходящим позициям выдачи Ozon |
| `Ozon: позиций` | сколько позиций попало в среднее |
| `Яндекс Маркет: средняя цена`, `: позиций` | то же по Маркету |
| `Wildberries: средняя цена`, `: позиций` | то же по WB |
| `Средняя по маркетплейсам` | среднее по тем площадкам, где что-то нашлось |
| `Отклонение от рынка` | `(ваша цена − средняя по маркетплейсам) / средняя`; плюс — вы дороже рынка |

Пустая ячейка «позиций» означает, что товар ещё не обрабатывался; `0` — что
запрос выполнялся, но подходящих позиций не нашлось. Это разные ситуации, и
различать их важно: первую лечит продолжение прогона, вторую — нет.

**Столбец «позиций» — не украшение.** Средняя по одной-двум позициям
статистически ничего не значит; для решений опирайтесь на строки, где
собралось 4–5 позиций.

## Как отбираются товары

Требование «сравнивать только соответствующие товары» — самая хрупкая часть
задачи, поэтому отбор устроен так:

1. **Запрос строится из головы названия.** Из
   `Пульт Radiomaster TX12 MKII ELRS + АКБ 18650 3000mAh (2шт)` получается
   `пульт radiomaster tx12 mkii elrs`: комплектация после `+`, внутренние коды
   поставщика в скобках и хвост характеристик отбрасываются — по полному
   названию маркетплейсы возвращают пустую выдачу.
2. **Если в названии есть артикул** (`X1605VA-MB2103`, `RB952Ui-5ac2nD-TC`),
   запрос обрывается на нём: он один задаёт модель.
3. **Каждая позиция выдачи проверяется** на совпадение артикула, модельных
   токенов (`s5322`, `380kv`, `9x4.5x3`) и бренда. `S5322 200KV` не зачтётся
   за `S5322 380KV`, а `Vivobook 15 X1504VA` — за `Vivobook 16 X1605VA`.
4. **Аксессуары отсеиваются:** чехлы, сумки, наклейки и стики к товару в
   среднее не попадают.
5. **Просматриваются первые 30 позиций,** из них берутся первые 5 подходящих —
   выдача замусорена, и подряд идущие пять позиций почти никогда не являются
   пятью нужными товарами.
6. **Ценовые выбросы отбрасываются:** позиция, отличающаяся от медианы группы
   более чем вчетверо, в среднее не идёт — так одиночный пропеллер не
   усредняется с набором из четырёх.

Фильтр намеренно строгий: пропустить товар безопаснее, чем усреднить цену по
чужому. Поэтому пустых ячеек будет заметное количество — это честный результат,
а не сбой.

## Что может пойти не так

**Капча на Ozon или Маркете.** Прогон отключает площадку после 12 ошибок
подряд, чтобы не тратить часы впустую. Увеличьте паузы в `mpc/config.py`
(`DELAY_OZON`, `DELAY_YM`), либо запустите с `--no-headless` и пройдите
проверку руками, затем `--retry-failed`.

**Пустой столбец WB.** Wildberries периодически меняет версию поискового API.
`mpc/sources/wildberries.py` понимает обе известные схемы ответа; если WB
перейдёт на следующую, поправьте `SEARCH_URL` и `_extract_price`.

**Пустой столбец Яндекс.Маркета.** Маркет сменил разметку. Селекторы вынесены
в начало `mpc/sources/yandex_market.py` — обновите `CARD_SELECTORS`,
`TITLE_SELECTORS`, `PRICE_SELECTORS`.

**Цены отличаются от тех, что видите вы.** Они зависят от региона. Регион WB
задаётся `WB_DEST` в `mpc/config.py` (по умолчанию Москва); Ozon и Маркет
определяют его по IP.

## Тесты

```bash
python -m unittest discover -s tests -v
```

26 тестов покрывают разбор названий, фильтр релевантности, усреднение с
отсевом выбросов, разбор цен обеих площадок и сборку итогового файла.

## Структура

```
run.py                       точка входа и цикл обхода
mpc/config.py                паузы, глубина выдачи, регион
mpc/normalize.py             разбор названий, построение запроса
mpc/relevance.py             проверка соответствия позиции товару
mpc/aggregate.py             отбор пятёрки и усреднение
mpc/storage.py               чекпоинт в SQLite
mpc/excel_io.py              чтение прайса и запись результата
mpc/browser.py               Chromium для площадок с антиботом
mpc/sources/wildberries.py   поисковый JSON-API
mpc/sources/ozon.py          composer-api через браузер
mpc/sources/yandex_market.py разбор DOM выдачи
```
